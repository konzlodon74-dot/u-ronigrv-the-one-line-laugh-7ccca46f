## The line

> I bought noise-cancelling headphones so I could focus, and now all I hear is how loud my own thoughts are.

## How it works

`main.py` writes that one original funny line to `/output/entry.txt`.
It is a single sentence of 106 characters — well within the 200-character limit.

```sh
python3 main.py
cat /output/entry.txt
```
